# castle

Small late-medieval castle from `scenes/castle.py` (voxel studio, docs: `docs/voxel-studio.md`), placed from code:

    python -m tools.voxel place scenes/castle.py --server castle --pristine     # meta origin (-64, 20, -64)

The pack sets fixed afternoon light, no mobs, and a G dialog (`demo.cs` trigger: 1-7 teleports, 8 creative, 9 survival, 10 spectator).
