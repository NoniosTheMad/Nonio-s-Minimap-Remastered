# vharzul

Vharzul, the Ember Throne: a showcase shell from `scenes/vharzul.py` (voxel studio; design notes in `scenes/vharzul.notes.md`,
zones in `docs/builds/vharzul-zones.md`), placed from code:

    python -m tools.voxel place scenes/vharzul.py --server vharzul --pristine     # meta origin (-104, 30, -100)

The pack sets fixed noon, clear weather and no mobs, and adds a G dialog (`demo.vz` trigger). Buttons 1-10 are teleports; 11-12 set Noon or Night; 13-14 switch Creative or Survival.
Rooms are empty named shells (unfurnished by brief).
