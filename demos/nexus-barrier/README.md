# nexus-barrier
Barrier (bossbar HP) protecting the obsidian Nexus, shown as a worldborder-style forcefield cube around it.
Hit the shell to damage it; obsidian is unminable until the barrier is 0.
G -> "Demo: Nexus Barrier": switch team, reset, regen speed, max HP, gear.

Game code: `datapack/data/nonios/function/nexus/` (visuals in `nexus/fx/`).
Visuals: `item_display` (tag nx.shield_fx) with item_model `nonios:nexus_shield[_cracked|_critical]`, tinted per team
via `dyed_color` (storage nonios:nexus col). Textures are generated by `tools/gen_nexus_shield.py` from the vanilla
`misc/forcefield.png` stripe pattern (32x32, 8 animated frames, translucent, grayscale for tinting).
- hit: white flash + bulge (display interpolation), sparks, shield sound; attacker gets an explain actionbar (max 1 per 15 ticks per player, gametime gate, no per-tick scan)
- HP <=50% cracked, <=25% critical + random flicker; regen mends back, full HP = pulse + chime
- 0 HP: shell bursts (scale 2.4) and is removed after 6t; spawn/reset: shell grows from 0 (re-form)
